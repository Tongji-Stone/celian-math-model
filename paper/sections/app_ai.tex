\section{AI 工具使用声明}

根据赛事论文格式规范，现就人工智能工具使用情况作如下声明。全文不出现参赛者姓名与学校信息。

\subsection{所用工具}

\begin{itemize}
  \item OpenAI ChatGPT（记录版本：1.2026.190，模型 gpt5.6-sol-high）
  \item OpenAI Codex CLI（记录版本：v0.147.0，模型 gpt5.6-sol-high；DeepSeek-V4-Flash-0731）
  \item 对话式编程助手（用于文献整理、问题一结果写入 LaTeX 论文框架）
\end{itemize}

\subsection{使用目的与环节}

\begin{enumerate}
  \item \textbf{讨论与协作：} 询问 Git 多人协作与仓库管理相关操作说明。
  \item \textbf{问题一：} 依据人工撰写的 \texttt{AGENTS.md} 生成模块化分析代码，完成 IQR 清洗、策略统一（9 种合并为 7 种）、200 圈汇总、49 张单体曲线与总图；人工检查可运行性后调整参数并复现 \texttt{log\_3}。
  \item \textbf{文献：} 整理快充、SOH 预测与策略优化相关公开文献条目，写入 \texttt{references/}。
  \item \textbf{论文：} 将第三次迭代后的问题一成果写入 LaTeX 正文，并为问题二至四保留章节框架。
\end{enumerate}

\subsection{提示方式}

主要方式为：先由人工完成题意分析与方法构想，再将任务写成 \texttt{AGENTS.md} 或结构化提示，交由 AI 生成代码或文档草稿，随后人工运行、核验数值与图件是否与数据一致。问题一提示词原文见 \texttt{A/问题一/AGENTS.md} 及 \texttt{log\_2.md} 附录，此处不重复粘贴以免附录过长；支撑材料中保留全文。

\subsection{采纳、修改与核验}

\begin{itemize}
  \item 问题一流水线经 \texttt{log\_3} 与验收确认：IQR 替换 559 格、策略 9\(\rightarrow\)7、200 圈样本 40 块、分位阈值 \(0.993433/0.996103\)、49 张单体曲线与 \texttt{SOH\_ALL} 齐全，与正文一致。
  \item 典型长/短寿命策略及 \(C_1>C_2\) / \(C_1<C_2\) 的解释以 \texttt{A/问题一/总结.md} 与 \texttt{policy.csv} 为准，因果表述保持为初步观察。
  \item 问题二至四的模型尚未给出最终数值，正文相应部分明确标注为框架。
\end{itemize}

AI 仅作为辅助工具，论文观点、模型选择与最终结论由参赛队负责。
