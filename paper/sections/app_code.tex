\section{建模源程序}
\label{app:code}

本节给出问题一至问题三可运行源代码。运行环境：Python 3，依赖 \texttt{numpy}、\texttt{pandas}、\texttt{matplotlib}；问题二另需 \texttt{scipy}、\texttt{statsmodels}；问题三的神经网络对照需要 \texttt{PyTorch}，外部 EOL 标定另需 \texttt{scikit-learn}。在项目根目录执行：
\begin{lstlisting}[language=bash]
python src/A/task1_pipeline.py
python src/A/task2_statistical_analysis.py
python src/A/task2_eol_analysis.py
python src/A/task3_window_ablation.py
python src/A/task3_external_eol_calibration.py
\end{lstlisting}
可选参数 \texttt{--iqr-factor}（默认 1.5）。单独绘制指定电池 SOH 曲线：
\begin{lstlisting}[language=bash]
python src/A/SOH_plot.py --battery-id 1
\end{lstlisting}
