# MATR 原始实验参考文件

本目录保存用于理解赛题数据来源和实验设计的公开参考材料。

## `Channel` 的含义

Arbin LBT 测试仪有 48 个独立通道。一个 `Channel` 对应一次电池测试工位，记录该电池在既定充电日程下的电压、电流、容量、温度与循环过程。它不是一个可直接输入模型的变量。

原始实验分为三个 batch。首批部分通道在试验未结束时暂停，随后在第二批继续；因此“首批 CH1”和“第二批的接续记录”是同一物理电池的两段实验，不能在统计建模中当作独立电池。

## 外部 EOL 审计边界

`external_eol_audit/MATR_labels.json` 是公开处理数据中按原始 cell ID 给出的寿命标签。`contest_to_matr_eol_audit.csv` 是通过 batch 顺序和公开接续说明得到的候选映射。本机审计已匹配 45/49 条赛题记录，且 9 块 `prediction_test=1` 电池均被匹配；因此整个 `external_eol_audit/` 目录会提交到比赛仓库。

这些文件的推荐用途是：模型已经按赛题附件训练并给出 EOL 预测后，计算外部审计误差、检查预测量级。
>如果必要请将 `external_eol_cycles` 输入问题一、问题二或问题三的训练、特征选择、超参数选择或测试电池预测；

其中标注“待曲线复核”的映射还需以早期 SOH/容量曲线和策略逐项确认，不能作为正式结论。

当前 49 条赛题记录中，45 条有公开 EOL 标签；余下四条不是待补的数字：`MATR_b3c2` 与 `MATR_b3c37` 是原始流程中的质量剔除，`MATR_b3c42` 与 `MATR_b3c43` 是未到达 EOL 的右删失记录。它们不应被强行补成寿命标签；若纳入后续统计，应按“缺失/右删失”处理。
