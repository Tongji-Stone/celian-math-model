\section{建模源程序}
\label{app:code}

本节给出问题一至问题四可运行源代码。运行环境：Python 3，依赖 \texttt{numpy}、\texttt{pandas}、\texttt{matplotlib}；问题二至四另需 \texttt{scipy}；问题三融合模型另需 \texttt{torch}。在项目根目录执行：
\begin{lstlisting}[language=bash]
python src/task1_pipeline.py
python src/task2_statistical_analysis.py
python src/task2_exposure_model.py
python src/task3_degradation_model.py
python src/task3_pbt_batterygpt_fusion.py
python src/task4_optimize.py
\end{lstlisting}
可选参数 \texttt{--iqr-factor}（默认 1.5）。单独绘制指定电池 SOH 曲线：
\begin{lstlisting}[language=bash]
python src/SOH_plot.py --battery-id 1
\end{lstlisting}
