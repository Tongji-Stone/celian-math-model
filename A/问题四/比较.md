# 问题四：Tongji-Stone 问题二各模型能不能拿来优化

比较时点：2026-08-16。优化脚本 `src/A/task4_optimize.py`。

## 1. 结论

**能用的是两窗口 PySR（与 WLS 同结构），而且主要当约束，不当精细目标。**  
岭回归 / OLS / PLS / 自由 PySR / 物理先验 PySR 都不能拿去搜新配方。问题三模型全部不能评价未实验 \(x\)。

## 2. 各模型在问题四里的角色

| 模型 | 问题二表现 | 问题四 | 原因 |
|---|---|---|---|
| 两窗口 PySR / WLS | 留一策略平均 RMSE 0.0021；短寿组仍能外推到 0.031（实测 0.034） | **主模型：约束 + 核对** | 能识别 \(C^{\mathrm{high}}=5.9\) 的灾难区；长寿区内预测差不可分辨 |
| \(Y\sim C^{\mathrm{high}}\) | 调整 \(R^2=0.775\) | 约束变量 | 比三元系数可读 |
| 岭 / OLS / PLS | 电池 LOOCV RMSE 0.0033–0.0046 | **反例** | \(C_1\) 为负，最优角点是 5.6C×80% |
| 自由 PySR | 留一策略 RMSE 0.009，短寿组 0.030 | **反例** | 公式随留出策略改变 |
| 物理先验 PySR | 留一策略 RMSE 0.011 | 不用 | 未通过问题二筛选 |
| 问题三近段线性 / 融合 | 151–200 RMSE 0.00027 / 0.00022 | **不用** | 需要该电池早期曲线 |
| 公开 \(N_{0.88}\) | 外部审计 | **不用** | 禁止进入训练或测试预测 |

## 3. 若误用对照模型会得到什么

| 优化器 | 盒约束“最优” | 该点 \(C^{\mathrm{high}}\) | 两窗口 Fade |
|---|---|---:|---:|
| OLS / 岭 | 5.6C(80%)-5.9C | 5.6 | 0.075（差于短寿组） |
| 自由 PySR | 5.6C(80%)-4.0C | 5.6 | 0.075 |
| 两窗口 + 约束 | 正式：已实验 5.3C(54%)-4C | 4.17 | 与实测 0.0026 一致 |

## 4. 和问题一、三的关系

问题一已经指出：长短寿充电时间都约 10.04 / 10.13 min（清洗后逐圈 `chargetime`），差别在 \(C_1>C_2\) 还是高 SOC 大电流。问题四改用同一口径后，\(\hat\beta\) 从 0.198 min 降到 0.045 min，两阶段 \(T_{\mathrm{CC}}\) 仍几乎锁在 10 min，多目标在样本内接近“只约束衰减”。

问题三说明近段斜率能预报再走 50 圈，但不能把 9 块测试电池的 \(\hat N\) 当成新配方的寿命。外部审计里那些圈数相对 0.88 Ah 系统性偏长，更不能当优化目标。
