# 问题三：逐电池退化曲线 vs 机器学习思路

比较时点：2026-08-15。`src/` 与 `A/` 下**没有**问题三的 LSTM / XGBoost / 随机森林等实现，论文 `03_problem3.tex` 仍是待填框架。因此不能做「两个已训练学习器」的数值对打。

下面分三层：概念差异、本脚本里已经能算的跨电池对照、机器学习补齐后应如何比。

## 1. 两种思路分别用什么信息

| | 本目录（逐电池 \(f\)） | 论文框架中的机器学习 |
|---|---|---|
| 输入 | 该电池自己的 1–150 圈 `SOH_smooth` | 策略参数、斜率、IR/T、分段 \(\Delta\mathrm{SOH}\) 等，在**其他电池**上学习映射 |
| 151–200 | 把本电池近段斜率延长 50 圈 | 用学到的映射输出后续 SOH 或衰减率 |
| \(\hat N_{\mathrm{EOL}}\) | 解 \(f(n)=0.8\) | 附件**没有** 80% 标签，不能做真正的监督寿命学习；若用伪标签，等于模仿某条 \(f\) |
| 样本 | 每块 150 个点估 1 个斜率 | 约 40 条电池级样本 |

## 2. 现有数值：跨电池对照已经输给逐电池

`policy_mean` 不用神经网络，但信息结构相同：**斜率来自同策略别的电池**，只借用本电池第 150 圈的水平。这是「跨电池学习」的下限版（更不容易过拟合）。

\(k=150\)、40 块截断验证：

- 近段线性 RMSE **0.000271**
- 策略均值 RMSE **0.000867**（约 3.2 倍）
- 第 150 圈沿用 RMSE **0.001530**（约 5.6 倍）
- 向策略收缩（70% 个体 + 30% 策略）RMSE **0.000734**，介于两者之间，**没有**超过纯个体近段斜率

结论：在「再走 50 圈、曲线仍接近直线」这个任务上，**别的电池帮不上忙，还会稀释本电池已经看见的斜率**。树模型 / LSTM 若主要靠策略和组间特征，预期不会优于 `policy_mean` 太多；若特征里已经包含本电池近段 \(\Delta\mathrm{SOH}\)，则与 `linear_recent` 同类，需要证明还有额外增益。

测试集上两者会分叉的例子：电池 9（`4_8C`）近段掉得快，逐电池 \(\hat N\approx 1679\)，策略均值 \(\approx 10100\)。电池 16（短寿）两者接近（1030 vs 1126），因为组内斜率本来就陡。

## 3. 机器学习文件补齐后怎么比才公平

用**同一批** 40 块、同一截断：只给 1–150，预报 151–200，比较 RMSE / MAE / \(\mathrm{SOH}_{200}\) 误差。不要用训练集 \(R^2\) 或无法验证的 \(\hat N_{\mathrm{EOL}}\) 宣称 ML 更好。

建议同时报告：

1. 纯逐电池 `linear_recent`（本目录主模型）
2. `policy_mean`
3. 机器学习（有/无 \(C_1,Q_1,C_2\) 的消融）

若第 3 项的 151–200 RMSE 没有稳定低于第 1 项，正文应以逐电池 \(f\) 为主，ML 作对照。80% 寿命一律由 \(f\) 外推并标明不确定度，不要用没有标签的网络直接输出圈数。

## 4. 当前判断

- **近处（151–200）**：逐电池近段线性更可靠。现有跨电池对照差距约 3 倍，方向与事先分析一致。
- **远处（80%）**：两边都没有真值；显式 \(f\) 至少假设清楚。ML 不能从附件里「学会」寿命。
- **问题四**：只能用问题二的策略层 \(g\)（如 \(C^{\mathrm{high}}\)），不能用问题三的个体曲线去优化未实验的配方。

待机器学习脚本进入仓库后，把其验证表并入本文件的第 2 节即可，不必改主模型代码。
